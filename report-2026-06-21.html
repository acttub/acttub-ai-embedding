추가역할

결합 수학

각 모달을 L2정규화한 뒤 √w를 곱해 concat하면, 결과가 자동으로 단위벡터가 되고 코사인이 가중 분해된다:

combined = concat([√(1-w)·영상_norm, √w·음성_norm])
→ ||combined|| = 1
→ 코사인 = (1-w)·영상코사인 + w·음성코사인

차원이 달라도(영상 1024 + 음성 512) 문제없고, 가중치 w로 "영상 더 볼지 음성 더 볼지" 런타임 조절.

  • app/CLI에 음성 가중치 슬라이더/옵션 (0=영상만 · 1=음성만)
  • index.npz 멀티모달 재구축 (C-pro 34개: video 1024d + audio 512d)

4. AI 코치 피드백 카드 — Gemini A/B 비교

유사검색만으로는 "닮은 영상"까지만 보여준다. 그 위에 실제로 뭘 고치면 되는지를 배우 언어로 짚는 피드백 카드를 Gemini로 생성. 원래 스코프 축소로 잔재였던 "Gemini 영상 피드백"을, 이번엔 유사검색 결과를 활용하는 형태로 되살렸다.

추가역할
gemini_feedback.build_prompt배우 설정 4개(매체·상황·인물·서브텍스트)를 prompt.txt 자리표시자에 채움. 빈 칸은 "비어 있음" 결측 표시
gemini_feedback.generate_feedback영상 업로드(ACTIVE 대기) → Gemini 호출 → 카드 JSON 파싱. ref_video 주면 C-pro를 "전문가 기준선"으로 동봉
gemini_feedback.parse_feedback_json모델 응답에서 ```json 펜스/잡설 벗기고 첫 {~마지막 }만 파싱
gemini_feedback.render_card_markdown카드 JSON → 사람이 읽는 마크다운(강점·관찰·원인·연습·기대효과)
gemini_feedback.load_env외부 의존성 없는 미니 .env 로더 (GEMINI_API_KEY). 기존 환경변수는 안 덮음
app.compare_feedback유사검색 top-1 C-pro를 찾아 A(입력만) vs B(C-pro 동봉) 카드 2장 생성·비교

A/B 비교 설계

같은 입력 영상에 대해 두 가지로 피드백을 뽑아 나란히 보여준다:

  • A — 입력 영상만 주고 피드백
  • B — 가장 닮은 C-pro 영상을 "전문가 기준선"으로 함께 주고 피드백

B에는 _REF_PREAMBLE로 "첫 영상은 평가 대상이 아니라 잘된 연기의 기준선, 피드백은 오직 두 번째 배우 영상에 대해서만"을 못박아 C-pro를 채점하지 않게 막았다. 유사검색이 피드백 품질을 실제로 끌어올리는지 눈으로 비교하는 게 목적.

프롬프트 (prompt.txt) — 5단계 내부 추론

관찰 → 진단 → 카드 초안 → 톤 다듬기 → 전문가 패널 검토를 모델 내부에서 돌리고, 최종 출력은 overallStrength + feedbackCards JSON 하나로만 고정(API 계약 유지).

  • 핵심 규칙: 영상에서 "실제로 보이고 들린 것"에만 근거 — 어림 타임코드·지어낸 대사·일반론 금지
  • 표면(가면) vs 누수 둘 다 관찰 → 과소/과잉 방향 판정 → 더하기/빼기 처방
  • 매체 보정(영화=절제 / 연극=객석 전달), 충돌 1개·강점 1개·바로 따라할 처방

출처: 우영이 프롬프트에서 변수명만 맞춘 버전.

⚠ 유료 API — Gemini는 유료 호출이라 자동 실행 금지. 코드/테스트만 작성했고 실제 호출은 사용자 명시 허가 시에만. 테스트는 전부 _FakeClient mock으로 돌려 네트워크·과금 0. app.py의 A/B 버튼을 눌러야만 실제 호출된다.

5. 기술적 발견 (gotcha)

  • V-JEPA 토큰 8192 = 32(시간) × 256(공간) — 실측 확인(probe_tokens.py). 구간 매칭의 근거.
  • CLAP은 10초 초과 입력을 랜덤 구간으로 잘라(rand_trunc) 비결정적 → 10초 청크로 나눠 평균내 회피 + 전체 반영.
  • transformers 5.x API 변경: audios= → audio=, get_audio_features가 output 객체 반환 → .pooler_output(512d).
  • PyAV 17: av.AVError → av.FFmpegError로 개명.
  • uv가 PATH에 없음 → py -m uv ...로 호출. .venv엔 pip 없음(uv 프로젝트).
  • Gemini SDK는 지연 import — from google import genai를 _client() 안에서만. SDK 미설치·키 없어도 모듈 import/테스트는 통과(유료 경로를 격리).
  • Gemini 영상 입력은 업로드 후 ACTIVE 대기 — PROCESSING 동안 폴링하다 ACTIVE 돼야 호출 가능.

6. 정성 검증 포인트 열린 항목

  • 토큰 time-major 가정 — embed_segments는 토큰 순서가 (시간, 공간)이라 가정. V-JEPA 2 표준이지만 100%는 아님. 실제 영상으로 구간 설명이 말 되는지 검증 진행 중.
  • 사용자 관찰: 질의/C 구간이 같게 나오는 경우 있으나 정밀 매칭은 비요구사항 (대략 범위면 OK).
